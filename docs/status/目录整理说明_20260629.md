# 目录整理说明（2026-06-29）

## 整理原则

- 保留有效代码入口，不移动 `preprocess/`、`construct/`、`scripts/`、`train/`，避免破坏脚本相对路径。
- 不删除任何历史文件；明显不用或系统生成的内容统一放入 `useless/`。
- 文档、参考资料、本地样本、外部评测代码按用途归档。
