## xcodemind/webcode2m

**Description:** WebCode2M - 3M web page screenshots with HTML source. Our primary training data source.

**Total rows:** 3,171,024

**Available configs/splits:**
- `default` / `train`

**Fields:** `image`, `bbox`, `text`, `score`, `scale`, `lang`, `tokens`, `hash`

**HTML Assessment:**
- Field name: `text`
- Content length: ~6,696 chars (sample)
- Has DOCTYPE: Yes
- Has `<html>` tag: Yes
- Has `<head>`: Yes
- Has `<body>`: Yes
- Has `<style>` tag: Yes (CSS already inlined into style blocks)
- Has inline style attribute: No (uses `<style>` blocks)
- Has external CSS links: No
- Has remote images: Yes (relative paths like `/static/img/...`)
- Has `<script>`: Varies
- **Self-contained CSS: Yes**

**HTML Preview (first 500 chars):**

```html
<!DOCTYPE html>

<!DOCTYPE html>

<html class="no-js"> <head><title>zip-stream :: Stackage Server</title></head><body><div id="main"><div class="navbar navbar-inverse navbar-static-top"><div class="navbar-inner"><div class="container"><button class="btn btn-navbar"><span class="icon-bar"></span><span class="icon-bar"></span><span class="icon-bar"></span></button><a class="brand"><img src="/static/img/stackage.png"/></a><div class="nav-collapse collapse"><ul class="nav"><li> <a>About</a></li><li>
```

**Notes:** CSS is embedded in `<style>` tags (already inline). Images use relative paths or remote URLs that need localization. This is our primary dataset.

## HuggingFaceM4/WebSight (v0.2)

**Description:** Synthetic HTML pages generated by LLMs, paired with screenshots.

**Total rows:** 1,922,671 (v0.2), 822,987 (v0.1)

**Available configs/splits:**
- `v0.2` / `train`
- `v0.1` / `train`

**Fields:** `image`, `text`, `llm_generated_idea`

**HTML Assessment:**
- Field name: `text`
- Content length: ~1,274 chars (short synthetic pages)
- Has DOCTYPE: No
- Has `<html>` tag: Yes
- Has `<head>`: No
- Has `<body>`: Yes
- Has `<style>` tag: No
- Has inline style attribute: No (uses Tailwind classes)
- Has external CSS links: **Yes (Tailwind CDN)**
- Has remote images: Yes (unsplash random images)
- Has `<script>`: No
- **Self-contained CSS: NO**

**HTML Preview (first 500 chars):**

```html
<html>
<link href="https://cdn.jsdelivr.net/npm/tailwindcss@2.2.19/dist/tailwind.min.css" rel="stylesheet">
<body class="bg-gray-100">
  <div class="flex flex-col items-center justify-center h-screen">
    <h1 class="text-4xl font-bold text-center text-gray-800">Fashion Brand</h1>
    <p class="mt-4 text-lg text-center text-gray-600">Explore the latest trends</p>
```

**Notes:** All pages depend on Tailwind CSS CDN. To use this data, we would need to either:
1. Download and inline the Tailwind CSS (~2.7MB minified, too large)
2. Resolve Tailwind classes to inline styles (complex but doable)
3. Use as-is and accept the external dependency

Pages are relatively short (~1-2KB) and simple. Good diversity of ideas.

## Recommendations

### Best datasets for training (ranked):

1. **xcodemind/webcode2m** (3.17M rows) - Our primary source. CSS already in `<style>` tags. Only needs image localization.
2. **xcodemind/webcode2m_purified** (2.56M rows) - Cleaned version, same format. Consider using this instead of raw.
3. **mrm8488/WebSight_70k** (70K rows) - Fully self-contained, no remote deps. Good supplementary data for simple pages.
4. **rishi-1001/webcode2m-improved-prompts** (14K rows) - High quality with better prompts. Good for fine-tuning.
5. **HuggingFaceM4/WebSight v0.2** (1.92M rows) - Large but requires Tailwind CSS resolution. Consider for scale if CSS can be inlined.

### For benchmark/validation:

6. **SALT-NLP/Design2Code-hf** (484 rows) - Real pages with fully inlined CSS. Matches Design2Code benchmark exactly.

### Key preprocessing needs by dataset:

| Dataset | CSS Work Needed | Image Work Needed |
|---------|----------------|-------------------|
| webcode2m | None (already `<style>`) | Localize remote URLs |
| webcode2m_purified | None | Localize remote URLs |
| WebSight v0.2 | Resolve Tailwind CDN | Localize unsplash URLs |
| mrm8488/WebSight_70k | None | None (no images) |
| Design2Code-hf | None (Bootstrap inlined) | Localize remote URLs |
| webcode2m-improved-prompts | None | Localize remote URLs |
