# WebRenderBench Samples

This folder contains a small local sample extracted from the publicly visible
rows on the Hugging Face dataset page for `aleversn/WebRenderBench`.

Important notes:

- These are real visible dataset rows, but not a full local mirror of the
  original dataset files.
- In the current environment, direct file download from Hugging Face stalled,
  so this sample was assembled from the public dataset viewer.
- The purpose is to help compare WebRenderBench with:
  - your current `case_part*` query pool
  - the repo shortlist for edit/repair

What this sample shows well:

- item naming convention
- file path pattern
- `element_count`
- `industry`
- `company_type`

What it does **not** include:

- a full local copy of the underlying webpages
- screenshots or all assets
- the complete train/test split

Source:

- https://huggingface.co/datasets/aleversn/WebRenderBench
