## 清洗流程

1. 读取 WebCode2M 原始 HTML。
2. 用官方 formatter 清理 HTML/CSS。
3. 提取可用资源到 `assets/`。
4. 去掉不可控远程渲染依赖：
   - remote stylesheet
   - remote script
   - remote image/font/css url
   - external form action
5. 对无法下载但影响布局的资源使用本地 placeholder。
6. 清理噪声：
   - analytics
   - ads
   - tracking pixel
   - preconnect / dns-prefetch
   - pingback / shortlink
7. 多页样本只接受真实站内 HTML 子页。
8. 写出 clean project。
9. 七类任务构造时再次调用 `copy_project()` 和 `sanitize_render_text()`，防止远程 URL 回流。
