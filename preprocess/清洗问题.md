# WebCode2M 清洗问题记录

## 当前已解决

1. **旧问题：远程资源残留**
   - 处理：构造阶段统一调用 `sanitize_render_text()`。
   - 当前验证：`remote_hit_count = 0`。

2. **旧问题：provenance 文件泄漏**
   - 处理：过滤 `metadata.json`、`original_webcode2m_screenshot.png`。
   - 当前验证：`provenance_hit_count = 0`。

3. **旧问题：单页硬造多页**
   - 处理：只接受真实站内 HTML 子页。
   - 当前结果：`webcode2m_official_multipage_10` 共 10 个项目、30 个 HTML 页面。

4. **旧问题：PRD 来源泄漏**
   - 处理：prompt 禁止出现 `screenshot`、`reverse construction`、`source website` 等词；validator 检查。
   - 当前验证：通过。

5. **旧问题：edit/repair 原型 patch 不严格**
   - 处理：接入 `web_coding_demo` 的 task catalog，并要求 LLM 输出可应用 search/replace。
   - 当前验证：所有保留样本都有 `label_modified_files`。

## 当前仍需注意

1. LLM 生成的 `<search>` 可能不是源码精确片段。
2. 失败样本不能硬算成功，必须丢弃或换样本补齐。
3. 无 HTML 的资源目录不能进入 image/video/repair 视觉任务。
4. Playwright 在本地沙箱内可能需要提升权限。
5. 扩量前先用文本 `qwen3.7-max` + 视觉 `qwen3-vl-235b-a22b-instruct` 重新跑每类 10 条确认质量；PRD 图片输入使用 VL 模型的 `image_url` 格式。
