# WebCode2M 七类任务构造方案

## 当前版本

- LLM endpoint：`https://app-hk.ppapi.ai/v1`
- 文本模型：`qwen-latest-series-invite-beta-v23`
- 视觉/PRD 模型：`qwen-latest-series-invite-beta-v23`
- 正式 smoke 输出：`WebCoding_Data/local_trials/webcode2m_formal_7x10_ppapi_smoke`
- 验证报告：`WebCoding_Data/local_trials/webcode2m_formal_7x10_ppapi_smoke/report.json`

## 已完成

1. 七类任务已拆成独立脚本，方便逐类检查：
   - `construct_text_generation.py`
   - `construct_image_generation.py`
   - `construct_video_generation.py`
   - `construct_text_editing.py`
   - `construct_image_editing.py`
   - `construct_text_repair.py`
   - `construct_image_repair.py`
2. `construct_webcode2m_dataset.py` 只做编排，不把七类逻辑塞进一个文件。
3. `text-generation` 已改成“代码 + 多页面多视口截图 -> PRD”，不是从标题/代码 heuristics 拼说明。
4. `text-editing` 严格对齐 `web_coding_demo/synthetic/edit.py` 的 16 类 task type，并让 LLM 同时生成 requirement 和 search/replace patch。
5. `text-repair` 严格对齐 `web_coding_demo/synthetic/repair.py` 的 11 类 defect type，采用 reverse construction：clean `dst` -> 注入缺陷 `src` -> 反转 patch 作为修复标签。
6. `image-editing` / `image-repair` 复用对应 text pair，只额外生成 `src_screenshot` / `dst_screenshot`。
7. `video-generation` 使用本地 Playwright 录屏，并调用 `human_like_playwright_record.py` 做滚动/点击/hover 等人类式轨迹。
8. 构造输出已做离线净化：去掉 provenance 文件，清理远程渲染依赖，保留 SVG namespace。
9. 已补验证器 `validate_webcode2m_task_dirs.py`。
10. 已生成每类 10 条，共 70 条样本，并通过验证。

## 七类任务定义

| 任务 | 输入 | 监督目标 | 构造方式 |
| --- | --- | --- | --- |
| `text-generation` | PRD 文本 | clean `dst` project | VLM 从代码 + 截图反推 PRD |
| `image-generation` | 多页面、多视口截图 | clean `dst` project | Playwright 截图 |
| `video-generation` | 页面浏览录屏 | clean `dst` project | Playwright 录屏 |
| `text-editing` | `src_code + 编辑需求` | `src -> dst` patch | edit.py task catalog + LLM patch |
| `image-editing` | text-editing + 截图 | 同 text-editing | 复用 text pair |
| `text-repair` | broken `src_code + bug 描述` | `src -> clean dst` patch | repair.py defect catalog + reverse patch |
| `image-repair` | text-repair + 截图 | 同 text-repair | 复用 repair pair |

## 运行命令

```bash
python3 WebCoding_Data/construct/construct_webcode2m_dataset.py \
  --input-dir WebCoding_Data/local_trials/webcode2m_official_multipage_10 \
  --output-dir WebCoding_Data/local_trials/webcode2m_formal_7x10_ppapi_smoke \
  --limit 10 \
  --edit-task-count 1 \
  --repair-task-count 1 \
  --max-retries 3 \
  --overwrite
```

验证：

```bash
python3 WebCoding_Data/construct/validate_webcode2m_task_dirs.py \
  --root WebCoding_Data/local_trials/webcode2m_formal_7x10_ppapi_smoke \
  --expected-per-task 10 \
  --report WebCoding_Data/local_trials/webcode2m_formal_7x10_ppapi_smoke/report.json
```

## 当前注意点

1. `text-editing` 对 search/replace 精确性敏感，失败样本不计入最终 10 条。
2. `text-generation` PRD 禁止出现 `screenshot`、`reverse construction`、`source website` 等来源泄漏词。
3. `image-*` 和 `video-*` 需要 Playwright/Chromium 权限；本地沙箱内可能需要提升权限运行。
4. `.env` 只本地使用，不提交。
5. `qwen-latest-series-invite-beta-v23` 已写入本地 `.env`，但当前 ppapi chat/responses 探针返回模型不可调用，需要确认服务端权限或接口路由。
