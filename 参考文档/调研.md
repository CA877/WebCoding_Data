### 2.5 相关工作的主要贡献

| 工作 | 主要贡献 | 是否训练/SFT 模型 | 对我们的直接启发 |
| --- | --- | --- | --- |
| WebSight | 大规模合成 screenshot-to-HTML/CSS 数据；HTML 中嵌入 CSS；v0.2 加入真实图片和 Tailwind | 是，公开过基于 WebSight fine-tuned 的 VLM | 样本要有截图、代码、token 控制；CSS 尽量直接可见；真实图片比纯占位更有价值 |
| Design2Code | 真实网页 screenshot-to-code benchmark；移除外部依赖；多媒体用 placeholder；人工检查可独立运行 | 主要是 benchmark/evaluation，不是重点训练新模型 | 最终样本必须离线可运行；图片缺失可以 placeholder；不要让模型编造外部依赖 |
| WebCode2M / Vision2UI | 真实网页大规模数据；包含 screenshot、HTML/CSS、bbox/layout、score、lang、tokens；提出 TreeBLEU | 是，训练/评估 WebCoder baseline | metadata 和 layout tree 很值得借鉴；但不能照搬单文件且资源不完整的 preview 形态 |
| Web2Code | 大规模 webpage-to-code instruction 数据和评测框架；评估网页理解与代码生成 | 是，用于 instruction tuning / MLLM 评测 | 我们也要把数据构造成可训练指令样本，并保留渲染评测闭环 |
| FullFront | 覆盖前端完整 workflow：设计、视觉理解、代码生成；把真实网页转成 clean standardized HTML；关注交互实现 | 主要是 benchmark/evaluation | 不要只做静态截图到 HTML；应保留多页、交互、前端工作流能力 |
| WebRenderBench | 真实网页 HTML+resources+截图；本地 server 渲染；提出布局/风格一致性评价和 ALISA/RL 思路 | 有 RL/ALISA 训练框架规划或实现方向 | 我们当前 useful 来源最接近它；必须保留完整资源目录，并做本地渲染验证 |
