# WebCoding 评测协议

评测与浏览器验证必须区分预检查和正式结果。正式评测使用 `EVALUATOR_MODE=full`；`simple` 只能作预检查。官方 judge 结果单独保存，不能与本地检查混报。

修改网页生成或 Edit/Repair 逻辑后，应实际启动 Chromium，验证目标页面、所要求的交互状态、应保留的旧能力及未受影响页面。patch 回放、HTTP 200、截图成功、代码可解析或 `status=ok` 只证明局部门禁，不能单独证明样本正确。

验证器修改时，用正确样本和明显错误样本作资格测试。按当前任务阶段执行必要门禁，不新增未经授权的独立 judge、reviewer 或筛选阶段。
